# Bean There Add-on

Your coffee beans, and every espresso and pour over you brew with them. Made for logging a brew from your phone in a
few taps, and just as usable from a PC.

## Features

- Your beans: roaster, origin, roast, price and more
- Espresso and pour over, each with its own tries
- Grind, dose, yield, time and how it tasted
- Each try starts from your last one
- The sweet spot of every coffee, at a glance
- Live on every screen

## Installation

1. Add this repository to Home Assistant, or copy this directory to your Home Assistant `/addons` folder
2. Refresh the add-on store
3. Install the "Bean There" add-on
4. Start it, and turn on "Show in sidebar"

## Configuration

| Option     | Default | What it does                    |
|------------|---------|---------------------------------|
| `currency` | `€`     | The symbol prices are shown with |

## Usage

Open **Bean There** in the Home Assistant sidebar
or go straight to `http://<your-homeassistant-ip>:3300/`.
